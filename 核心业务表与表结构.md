## 当前应用映射结论（2026-08-20）

`LIS_DCIRCSLOG` 已确认为环境/仪器监测记录正式明细表。页面与业务表按以下关系固定：

```text
LIS_LIBDEF.LIBSEQ
  -> LP_TBC_INSTFILE.LIBSEQ
  -> LIS_MCIRCSLOG.LIBSEQ

LP_TBC_INSTFILE.INSTID
  -> LIS_MCIRCSLOG.INSTID

LIS_MCIRCSLOG.CIRCSLOGSEQ
  -> LIS_DCIRCSLOG.CIRCSLOGSEQ

LP_TBC_CIRCUDEFM.CIRCUITEMID
  -> LIS_DCIRCSLOG.CIRCUITEMID
```

页面稳定键：实验室 `LAB:LIBSEQ`、仪器 `INST:INSTID`、监测明细 `CIRCSLOGSEQ:CIRCUITEMID`。一次主记录对应多个项目明细；不能使用主表 `IFOK` 伪造明细值，也不能按页面序号、相近名称或相近编号猜测对象关系。

当前真实数据量为：`LIS_LIBDEF=202`、`LP_TBC_INSTFILE=244`、`LP_TBC_CIRCUDEFM=3`、`LIS_MCIRCSLOG=33`、`LIS_DCIRCSLOG=0`。33 条主记录当前不能关联现有实验室和仪器档案。现阶段可以展示对象档案、项目定义和实验室温湿压要求；不能展示真实监测值、最新值、趋势或数值统计。

厂家后续对接需要补齐：

1. 采集对象与 `LIBSEQ/INSTID` 的稳定映射；
2. 一条主记录与多条明细的事务写入和幂等重传；
3. `CIRCUITEMID/ITEMCODE`、单位、精度及 `IFOK/FTYPE/FMODE` 字典；
4. 设备时间、服务器接收时间、断线补传和原始报文留存；
5. 机构隔离链路和可验证真实样例。

外部接口、实时在线状态、采集执行日志、预警通知/处置和远程控制使用独立数据源，不在这五张环境业务表中伪造。
