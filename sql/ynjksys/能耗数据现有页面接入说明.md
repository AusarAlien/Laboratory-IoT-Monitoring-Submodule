# 能耗数据现有页面接入说明

> 业务主键、表职责、历史数据兼容和机构隔离统一遵循仓库根目录的《开发指导与数据关联边界》。本文仅记录当前能耗页面的实现和 SQL 文件。

本次不新增业务页面。`HII.IB_TBS_DEVICEMONITORLOG` 的真实数据接入以下既有需规页面：

| 优先级 | 页面 | 已接入区域 | 未使用能耗日志替换的区域 |
| --- | --- | --- | --- |
| 1 | 物联查询统计 | 设备和指标筛选、明细、功率等趋势、状态分布、自定义统计 | 无 |
| 2 | 数据采集管理 | 设备采集结果、结果筛选、结果详情和导出 | 采集批次统计、成功率、失败次数、采集执行日志 |
| 3 | 物联状态监测 | 实时状态、状态统计、状态变化、状态字典 | 无 |
| 4 | 监测预警管理、智能预警 | 暂不接入 | 阈值、预警事件、处置和推送记录均不能由普通监测日志替代 |

## 指标映射

| 数据库字段 | 页面指标 | 页面单位 | 转换 |
| --- | --- | --- | --- |
| `FCURRENT` | 电流 | A | 原值 |
| `FVOLTAGE` | 电压 | V | 原值 |
| `FPOWER` | 功率 | kW | 除以 1000 |
| `FTTLENERGY` | 总能耗 | kWh | 原值 |
| `FTTLUSETIMER` | 总使用时长 | h | 原值 |
| `FPOWERFACTOR` | 功率因数 | 无 | 原值 |

总能耗和总使用时长属于累计值。自定义统计中的“累计增量”按查询分组内最大值减最小值计算，不直接累加每条累计记录。

## 查询注册顺序

1. `ynjksys_wljk_nh_sb01q-能耗设备查询.sql`
2. `ynjksys_wljk_nh_jl01q-能耗指标记录查询.sql`
3. `ynjksys_wljk_nh_hz01q-能耗指标汇总查询.sql`
4. `ynjksys_wljk_nh_qs01q-能耗指标趋势查询.sql`
5. `ynjksys_wljk_nh_zt01q-能耗设备实时状态查询.sql`
6. `ynjksys_wljk_nh_bd01q-能耗设备状态变化查询.sql`

设备档案采用左连接。`LP_TBC_INSTFILE.INSTID` 无匹配记录时，设备名称显示为“设备 + INSTID”，能耗日志仍正常返回。

实时状态优先使用 `IB_TBS_ITLASTINSTSTATUS.FDEVICESTATUS`，缺少最新快照时回退历史 `FSTATUS`。最后通信时间超过 180 秒为离线；未超时时再映射已知状态，空值或未识别值为未知。

## 2026-08-14 数据关联完善

- 仪器业务对象继续按 `能耗表.INSTID = LP_TBC_INSTFILE.INSTID` 左连接，`FSSID` 作为插座/采集端单独展示。
- 设备、历史记录和趋势查询增加正式仪器编号、型号、科室、位置及插座字段；档案缺失时继续使用原有降级值。
- 实时状态查询改为优先读取 `IB_TBS_ITLASTINSTSTATUS`，只有缺少最新快照时才回退 `IB_TBS_DEVICEMONITORLOG` 的最后记录。
- 最新状态表没有 `FHIINO`，通过当前机构历史设备集合或当前机构仪器档案限制范围。
- 多插座仪器的趋势按“仪器 + 插座”拆分曲线，避免不同采集端数据交错连接。
- `IB_TBS_SMARTSOCKETLOGSHOW.FTYPE` 含义尚需以实际数据确认，本批不猜测替换累计值统计。
